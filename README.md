# «Лапа & Хвост» — учебный интернет-магазин

## Страницы

- `index.html` — главная с категориями, популярными товарами, преимуществами и FAQ.
- `catalog.html` — каталог с поиском, фильтрами по категориям и цене, сортировкой.
- `product-dog-food.html`, `product-cat-food.html`, `product-carrier.html`, `product-toy.html`, `product-scratch.html`, `product-hygiene.html` — карточки товаров.
- `cart.html` — изменение количества, удаление, учебный промокод `LAPKA10`, выбор доставки.
- `checkout.html` — демонстрационная форма заказа с HTML5-проверками.
- `information.html` — о проекте, доставке, учебных данных и контактах.
- `404.html` — вспомогательная страница ошибки.

## Чеклист лабораторной работы

- [x] Многостраничный сайт магазина для варианта «Зоомагазин».
- [x] Семантические элементы HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`, `figcaption`, `details`, `summary`, `output`, `time`, `data` и другие.
- [x] Проверка полей: `required`, `type=email`, `type=tel`, `pattern`, `minlength`, `maxlength`, `min`, `max`; CSS-состояния `:valid` и `:invalid`.
- [x] Увеличение иллюстраций при наведении, поворот декоративных элементов на 180° и 360°, плавные `transition`.
- [x] Скорость перехода задаётся `ease`, `ease-in-out` и функцией `cubic-bezier(...)`.
- [x] Уважает `prefers-reduced-motion`.
- [x] Адаптивные макеты для контрольных ширин 320, 768, 1000 и 1280 px.
- [x] Базовая совместимость: без фреймворков, с системными шрифтами и стандартными HTML/CSS/JavaScript API.
- [x] Картинки — локальные SVG-иллюстрации, внешние сервисы не нужны.

## Проверки

- Проверено наличие doctype и viewport, сбалансированность HTML-тегов, подписи полей, локальные ссылки/иллюстрации и синтаксис `store.js`; ошибок в этих проверках не обнаружено.
- Для контрольных ширин 320, 768, 1000 и 1280 px предусмотрены отдельные CSS-диапазоны. Полный ручной прогон во всех четырёх размерах не выполнен.
- Визуальный просмотр главной выполнен во встроенном Chromium. Проверку в дополнительных браузерах и в официальном Nu HTML Checker завершить не удалось: браузерная автоматизация остановилась при переключении в Edge, локальный HTML-валидатор в окружении отсутствует.

Суммы и описания вымышлены для лабораторной работы. Это не коммерческое предложение и не рекомендации по питанию животных.
